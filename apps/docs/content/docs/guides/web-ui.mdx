The server serves a React single-page app next to the REST API at `http://localhost:3000`. Start the server as described in the [Quickstart](/docs/getting-started/quickstart) or [Install](/docs/getting-started/install#run-the-server) pages.

## First-run setup

On the first visit WebFrost shows a setup wizard that creates the admin account: a username and a password of at least 8 characters. After that you sign in with that username and password. There is one admin account.

<Callout type="warn" title="Login bounces back to the login page?">
The session cookie is `Secure`, so browsers drop it on plain-HTTP origins other than `localhost`. Serve WebFrost over TLS, or set `WEBFROST_INSECURE_COOKIES=true` for an HTTP-only deployment. See [Deploy](/docs/guides/deploy#tls-and-cookies).
</Callout>

## Pages

| Page | What it does |
|---|---|
| Dashboard | Four stat cards (Total Snapshots, Storage Used, Success Rate, Failed Today), a **Quick Archive** form and a **Recent Activity** feed grouped by day. |
| Snapshots | A virtualized list of every snapshot, newest first. Compact or comfortable density, inline filter by URL, status or tag, bulk selection with a floating delete bar, and a slide-over detail panel (`?id=...` in the URL). |
| Snapshot detail | Each extractor with duration, file size and a download link, tags, and a sandboxed preview of the DOM snapshot and SingleFile copy. |
| Search | Full-text search over the FTS5 index with highlighted snippets, filters by status and tag, and saved searches stored in your browser's `localStorage`. |
| Tags | Create and delete tags. A tag has a name and a hex color. Tag names are searchable. |
| Schedules | Create schedules from a cron expression or a preset. Each row shows a health badge (**On schedule**, **Overdue**, **Paused**, **Never run**), last-run status, consecutive failures and an expandable preview of the next 5 runs. Pause, resume and delete (with confirmation). |
| Import | Bulk import from an RSS feed URL, an OPML file, a Netscape bookmarks file or a plain URL list. Shows queued and skipped counts and the import history. See [Bulk import](/docs/guides/bulk-import). |
| Settings | Light or dark theme, change the admin password (all other sessions are signed out), and server info (version, storage path, snapshot count). |
| API keys | Create and revoke keys for the REST API and SDK. A key is shown once, when you create it. |

The UI creates URL schedules. A schedule that follows an RSS feed can only be created with the CLI: see [Scheduled archiving](/docs/guides/scheduled-archiving#rss-feeds).

## Read-only guest view

With `WEBFROST_PUBLIC_READ=true`, visitors can browse the archive without signing in. Guests get the Dashboard, Snapshots, Search and Tags pages, can open any snapshot, and can download or preview its files. A **Read-only** marker with a **Sign in** link appears in the sidebar. Everything that changes the archive appears only after signing in. See [Public read](/docs/guides/public-read) before turning it on.

## Navigation

The sidebar has primary items (Dashboard, Snapshots, Schedules, Tags) and secondary ones (Import, Settings). It collapses from 240 px to 56 px, and the state is remembered. On a phone it becomes a drawer opened from the top bar.

## Keyboard shortcuts

| Keys | Action |
|---|---|
| `Cmd+K` or `Ctrl+K` | Open the search palette |
| `?` | Show the shortcuts help |
| `g` then `h` | Go to Dashboard |
| `g` then `s` | Go to Snapshots |
| `g` then `t` | Go to Tags |
| `g` then `i` | Go to Import |

A `g` sequence times out after 1 second. Shortcuts are off while focus is in an input, textarea or select. In the search palette, type to search by URL or title, move with the arrow keys, press `Enter` to open a result and `Escape` to close.

## Theme

The UI follows your system light or dark preference on the first visit. Toggle it with the sun and moon icon in the sidebar footer. The choice is saved in `localStorage` (`webfrost-theme`).
